Validador de DNI en Flutter

Un proyecto práctico desarrollado en Flutter y Dart para validar y calcular automáticamente la letra oficial del DNI español utilizando la operación matemática módulo 23 

*Cálculo automático de letra: Algoritmo oficial basado en la secuencia estandarizada TRWAGMYFPDXBNJZSQVHLCKE.

*Validación de entradas:

**Control de longitud estricto (exactamente 8 dígitos).

**Control de tipos (solo caracteres numéricos).

**Gestión de entradas vacías.

*Interfaz limpia y reactiva: Construida con Material Design usando StatefulWidget y manipulación de estado con setState().

*Arquitectura modular: Separación clara de responsabilidades entre el punto de entrada (main.dart) y las pantallas/lógica del componente (calcularletra.dart).


Tecnologías utilizadas:

*Lenguaje: Dart

*Framework: Flutter SDK

*IDE: VS Code
